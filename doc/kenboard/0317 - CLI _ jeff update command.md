# CLI / jeff update command

Créer une commande jeff update qui enchaîne :
1. jeff sync (fetch contacts depuis CardDAV)
2. jeff publish (build le site HTML)

Une seule commande pour mettre à jour le CRM. Utilisée dans le cron quotidien.
